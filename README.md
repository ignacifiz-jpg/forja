# FORJA
Centro de mando personal para crear anuncios de e-commerce: generador de copy con IA, plantillas de prompts (UGC e imagen) y una base de datos con buscador que solo responde lo que sabe.

La web es un único archivo (`index.html`). Las funciones de IA usan tu propia API key, que se guarda solo en tu navegador (nunca en el código).
